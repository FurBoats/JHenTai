# JHenTai（Xray 增强版）

本仓库基于 [JHenTai](https://github.com/jiangtian616/JHenTai)，原作者 **JTMonster（jiangtian616）**。原项目的全部功能、文档与署名归原项目所有，完整说明请看原仓库。本仓库只加入了下面这些改动，其余行为与原版完全一致。

## 本仓库的改动

1. **内置 Xray 核心**（LibXray 26.10.31）。节点和订阅直接在应用内导入和运行，不需要再单独开代理软件。支持 vless / vmess / trojan / shadowsocks / socks / hysteria2。
2. **单主节点。** 全部流量只走一个主节点。原 `igneous` 专用节点已移除：`igneous` cookie 默认经应用自身的网络路径（已配置的代理/主节点）直连刷新；也可以改用自部署的刷新接口刷新——该功能默认关闭，只能在查看 Cookie 页长按 `igneous` 一行开启，开启前会明确提示你的登录 Cookie 将发送到该第三方接口。
3. **订阅作为一等对象管理。** 分组显示、多链接/多渠道拉取、手动刷新；纯链接、base64 订阅正文、Clash YAML 都能解析，base64 正文由桥接层在本地解码。
4. **Hysteria2 证书锁定。** 订阅里的 `pinSHA256` 会被转换成核心接受的 `pinnedPeerCertSha256` 字段并自动注入。
5. **主节点健康检查与按顺序回退。** 当前主节点不通时，自动切到列表里的下一个节点，并 toast 提示用户。
6. **Sad Panda 自动处理。** 在 EX 站点遇到空白响应时，自动强制刷新 `igneous` 并重载原请求一次，带 toast 提示。自动刷新在高级设置里有独立开关，连续失败 5 次后也会自动关闭。
7. **WebView 跟随应用的代理设置**；冷启动时先启动 Xray 核心再加载界面，首屏不再撞上连接被拒。
8. **下载走主节点代理**——画廊图片下载和归档下载都是。
9. **IP 封禁自动切换。** 站点返回「该 IP 因请求过快被临时封禁」类响应时，自动切换主节点、toast 提示用户，并重新加载请求。
10. **完整应用数据导出并入原有导出。** 原「导出数据」的选项里新增「完整应用数据」一项，勾选即导出 zip 包；原「导入数据」选择该 zip 即可完整恢复。
11. **云端超分（安卓与 Windows 双端）。** 高级设置 → 图片超分辨率新增「使用云端超分」开关（默认关；开启会把图片上传到云端节点，设置里有明确提示）。开启后超分改走远程 Real-ESRGAN 后端：画廊下载时把图片链接发给后端、归档下载时把压缩包链接发给后端、已下载的画廊/归档可长按把本地图片上传超分，倍率 2x/3x/4x。桌面端若已配置本地 ncnn 模型，优先走本地。后端由调度器派发（配套项目 `JH_SuperResolution_Scheduler` 与 `JH_SuperResolution`）；内置提供商节点可在构建时通过仓库 Secret `EHSR_BUILTIN_KEY` 注入，也可以填自己的调度器地址和 ClientKEY 使用自建节点。

## 下载

见本仓库 [Releases](../../releases)。Release 版本号规范为 `Jhentai-<JH版本>-<Xray版本>-<构建日期>`，例如 `Jhentai-8.0.18-26.10.31-20261119`。每个 Release 提供分架构 APK（arm64-v8a、armeabi-v7a、x86_64）、一个通用的 universal APK，以及 Windows 版（安装包和便携 zip）。
