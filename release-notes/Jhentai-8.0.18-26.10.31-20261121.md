## 云端超分（安卓 / Windows 双端）

- 高级设置 → 图片超分辨率新增「使用云端超分」开关（默认关）。开启后二选一：内置提供商节点（参数构建时注入，不在界面显示）或自定义节点（调度器地址 + ClientKEY，默认空）。
- 三个入口，倍率可选 2x / 3x / 4x：
  - 画廊下载时勾选云端超分：图片链接整批交给后端超分后回填，任一环节失败自动回退普通下载；勾选「下载原图」时超分选项自动缩回、不可选。
  - 归档下载对话框新增云端超分选项：把压缩包链接交给后端超分，结果包按原流程解包，官方与归档机器人来源都支持。
  - 已下载的画廊 / 归档长按菜单新增「云端超分」：把本地图片上传超分，结果与本地超分放在同一目录，阅读器无感知。
- Windows 上若已配置本地 ncnn 模型，长按入口优先走本地超分。
- 安卓端高级设置现在也能进入「图片超分辨率」页（本地超分部分仍只在桌面端显示）。
