## 本次更新

- 新增Windows客户端（真的会有人用吗？）：提供安装版与携带版，内置 Xray 机制与 Android 版一致（双节点分流、订阅导入与定时刷新、igneous 专用节点、主节点故障转移）
- Xray 本地代理默认端口改为 23366（igneous 刷新端口 23367），默认端口被占用时自动改用随机可用端口，Android 与 Windows 一致
- Windows 携带版：应用与账号数据保存在运行目录下的 JH_Data 文件夹（没有会自动新建）
- Windows 安装版：数据保存在 AppData 等不需要管理员权限的目录；安装最后可勾选「添加到开始菜单」「创建桌面快捷方式」；安装时侦测并显示已安装版本；卸载时可勾选「擦除应用数据」，且只会删除应用自己的数据目录，不会碰其他文件
- Windows：首次下载文件时弹出下载路径选择，默认填入系统下载目录下的 JHentai 文件夹
- Windows 阅读优化：滚轮翻页防抖（一格滚轮只翻一页，不再连跳），方向键 ↑/↓ 加入默认翻页快捷键
- 新增完整应用数据导出/导入（高级设置）：账号、全部设置、Xray 节点与历史记录打包为单个文件，Windows 安装版、携带版与 Android 之间可互通迁移；导入后应用自动关闭，下次启动时生效，来自其他机器的下载路径不会被带入
